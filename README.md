# Fake-News-Detection-Project

**Project Overview**

This project is a Machine Learning and Natural Language Processing (NLP)-based Fake News Detection System designed to classify news articles as either Real or Fake. The model utilizes TF-IDF Vectorization for effective text feature extraction and Logistic Regression for accurate classification.

The system was trained on a news dataset and achieved an accuracy of 98.66%. This project provided valuable experience in data preprocessing, text classification, machine learning model development, and predictive modeling techniques.

**Features**

- News classification (Real/Fake)
- Text preprocessing
- TF-IDF feature extraction
- Machine Learning model training
- Accuracy evaluation

  **Technologies used**
1) python
2) pandas(Data processing)
3) Numpy(Numerical Computing)
4) Scikit-learn(Machine Learning)
5) TF-IDF Vectorization(Text Feature Extraction)
6) Logistic Regression(Classification Algorithm)
7) CSV Dataset Handling

   
**Dataset**
The project uses the Fake and Real News Dataset from Kaggle.


**model accuracy**
model Accuracy: 98.66%

**How to Run**

1. Download or clone the project repository.
2. Install the required libraries:
   pip install pandas numpy scikit-learn streamlit
3. Run the Python file:
   py fake_news_detection.py
4. Enter a news article and view the prediction result.
5.  Run Web Application:
   py -m streamlit run app.py
6. Open the generated local URL in your browser.

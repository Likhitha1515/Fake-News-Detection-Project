# Fake-News-Detection-Project

**Project Overview**

This project uses Machine Learning and Natural Language Processing (NLP) techniques to classify news articles as Real News or Fake News.

**Features**

- News classification (Real/Fake)
- Text preprocessing
- TF-IDF feature extraction
- Machine Learning model training
- Accuracy evaluation

**Technologies Used**

- Python
- Pandas
- NumPy
- Scikit-learn
- NLP

**Dataset**

The project uses the Fake and Real News Dataset from Kaggle.

**Project Structure**

Fake-News-Detection/
├── Fake.csv
├── True.csv
├── fake_news_detection.py
└── README.md
